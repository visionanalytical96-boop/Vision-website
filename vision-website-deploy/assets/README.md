# Assets

Drop real Vision Analytical branding here and the app will pick it up
automatically - no code changes needed:

- `logo.png` - shown in the app header (recommended: square, at least 256x256, transparent background)
- `icon.ico` - Windows window/taskbar icon (multi-resolution .ico, e.g. 16/32/48/256)

Until these are added, the app draws a placeholder server-rack glyph in the
dark blue + cyan theme so the UI still looks intentional.
